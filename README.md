## Projetos em destaque

### C.R.I.S.I.S. — Unipar

Projeto desenvolvido em parceria com a **Unipar Carbocloro** para apoiar a evacuação segura da fábrica de Cubatão em situações de **emergência industrial**.

A proposta reúne:

* 🚪 Contagem anônima de entradas e saídas da planta
* 🪪 Registro da última zona identificada por RFID
* 🛟 Confirmação de chegada nos pontos de encontro por RFID
* 📊 Dados para apoiar as equipes de SSMA e do CCO
* 🚨 Apoio à resposta em emergências industriais

**PS:** repositório do projeto original é localizado no GitLab, onde realizamos tarefas e adicionamos conteúdo diariamente. Como o projeto tem data de finalização em dia 18/12/2026, o repositório aqui do GitHub pode estar desatualizado.

### 🛡️ Gestão de Áreas de Risco — GeoRisco

### 🎮 Game Development — Cobasi

Projeto desenvolvido em parceria com a Cobasi para criar uma experiência gamificada integrada ao contexto do aplicativo da empresa, utilizando mecânicas de jogo para **educar tutores de cães e gatos sobre as necessidades de seus pets e os produtos relacionados a esses cuidados**.

A solução foi pensada para transformar conteúdos sobre alimentação, saúde, comportamento, higiene e bem-estar animal em uma experiência mais simples, acessível e envolvente.

O projeto envolveu o desenvolvimento de fases, desafios e interações educativas, explorando elementos de gamificação como pontos, níveis, recompensas e possíveis pets virtuais.

Tecnologias: JavaScript · Phaser 3 · HTML · CSS

Principais aprendizados:

🎮 Desenvolvimento de jogos e mecânicas de gameplay

🧩 Implementação de desafios e sistemas de interação

🐶 Aplicação de conteúdo educativo em experiências digitais

🎨 Design de interfaces e experiência do usuário

💻 Desenvolvimento de aplicações interativas com JavaScript

**Acesso:** [https://github.com/davitricarico-wq/g05.git](https://github.com/davitricarico-wq/g05.git)
